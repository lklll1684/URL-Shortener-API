# URL-Shortener-API
Сервис для сокращения ссылок, написанный на FastAPI с поддержкой кэширования через Redis, авторизацией по JWT и полной докеризацией.
Database: SQLAlchemy (ORM)
Сокращение URL, генерация уникальных 6-символьных кодов, кэширование ссылок в Redis для мгновенного ответа, счетчик кликов/переходов по каждой ссылке, регистрация, вход и защита эндпоинтов через JWT, личный кабинет с просмотром и управлением только своими ссылками.
Запуск через Docker Compose: запуск контейнера docker-compose up --build, после запуска интерактивная документация будет доступна по адресу: http://localhost:8000/docs
